# ItzFuzz — Scroll-Driven Hero Animation

A premium scroll-driven hero section inspired by the provided reference, built with **Next.js, Tailwind CSS, GSAP and ScrollTrigger**.

## Features

- Above-the-fold hero layout
- Letter-spaced animated headline
- Staggered metric reveal on initial load
- Scroll-scrubbed car/object movement
- Parallax background orb and typography
- Transform-based animation for smoother rendering
- Responsive mobile layout
- Static export configured for GitHub Pages
- GitHub Actions deployment workflow

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## GitHub Pages

Create a repository named `itzfuzz-scroll-animation`, push this project to the `main` branch, then enable **GitHub Actions** as the Pages source in repository settings. The included workflow builds and deploys the `out` folder automatically.

Live URL after deployment:

`https://YOUR_USERNAME.github.io/itzfuzz-scroll-animation/`
